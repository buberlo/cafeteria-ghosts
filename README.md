# Cafeteria Ghosts

> Every unpaid food order becomes a phone haunting until you settle the tab.

A mobile app that turns forgotten meal orders, split bills, and refunded snacks into mischievous ghosts. Each ghost nudges your phone with escalating hauntings until you pay, apologize, or feed it a fake receipt. The goal is to keep your wallet calm and your phone from rattling.

## Features
- Create food ghosts from manual orders, receipts, or split-bill notes
- Escalate hauntings with vibration patterns and ghostly push messages
- Negotiate with ghosts using apology templates and bribe chips
- Track a haunting ledger showing how much peace you bought back

## Stack
- React Native
- Firebase
- OneSignal

## Getting started
```
npm install; copy .env.example to .env with Firebase and OneSignal credentials; run npm run android or npm run ios.
```
